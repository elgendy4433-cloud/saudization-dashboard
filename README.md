## 🚀 المميزات الرئيسية للوحة:

1. **📊 مؤشرات الأداء وجدول الامتثال المفصل**:
   - المؤشر المدمج (النسبة المطلوبة + النسبة الحالية) لكل مجموعة مهنية.
   - متابعة دقيقة لأعداد السعوديين الملتزمين بالحد الأدنى للأجور، إجمالي السعوديين، المقيمين، وإجمالي الكوادر.
   - شارات امتثال ذكية (محقق للنسبة / دون النسبة).
   - زر `📄 فتح الدليل ↗` المباشر لفتح الدليل الإجرائي المعتمد من موقع الوزارة في صفحة مستقلة.
   - زر `ℹ️ ملخص` لاستعراض ملخص الوظائف واشتراطات الأجور في نافذة سريعة.

2. **⏳ عداد تنازلي حي للقرارات المستقبلية مع لوحة تحكم كاملة**:
   - متابعة لحظية بالثانية (أيام : ساعات : دقائق : ثوانٍ) حتى تاريخ الإلزام الوزاري للقرارات القادمة (مثل مهن إدارة المشاريع بتاريخ 14 فبراير 2027، والمهن المحاسبية، والمهن الهندسية).
   - **لوحة تحكم مرنة**: تمكن مدير الموارد البشرية من تحديد وتعديل تاريخ الهدف أو استهداف مراحل مستقبلية لأي مهنة وتفعيل/إيقاف العداد التنازلي لها فورياً.

3. **📅 المخطط الزمني وتواريخ سريان القرارات**:
   - استعراض تسلسلي تاريخي لقرارات التوطين والمهل الوزارية الممنوحة للمنشآت.
   - تمييز لوني فوري بين القرارات النافذة والقرارات ذات السريان المستقبلي.

4. **📚 دليل القرارات والأنظمة الوزارية المنشورة**:
   - بطاقات تعريفية مفصلة لكافة القرارات الوزارية الـ 13.
   - روابط تنزيل ومطالعة الأدلة الإجرائية الرسمية مباشرة من وزارة الموارد البشرية.

5. **🎯 محاكي قرارات التوظيف وفجوات التوطين الذكي**:
   - اختبار فوري لأثر استقطاب سعوديين أو إضافة مقيمين على نسب التوطين ونطاق المنشأة.
   - حساب الفجوة العددية المطلوبة لتحقيق الامتثال 100%.

6. **🏛️ دليل الهيئات وجهات الاعتماد والتراخيص المهنية**:
   - ربط المهن بجهات الاعتماد الرسمية (الهيئة السعودية للمهندسين، هيئة المحاسبين والمراجعين SOCPA مع شرط 5 محاسبين فأكثر، الهيئة السعودية للتخصصات الصحية، وزارة العدل / هيئة المحامين).

7. **🌙 نظام ليلي ونهاري متكامل (Dark Mode)**:
   - زر تبديل سلس أعلى اللوحة مع حفظ التفضيل تلقائياً في المتصفح.

8. **📥 تصدير واستيراد البيانات (Excel)**:
   - دعم تصدير تقارير الامتثال المحدثة بصيغة Excel وطباعتها بنقرة واحدة.
